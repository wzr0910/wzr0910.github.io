## 关于「用户验证」的诚实说明

三个项目均为个人作品，处于早期验证阶段，由亲友与同专业同学小范围内测。用户洞察来自自身使用与内测口述反馈整理，**不是大规模问卷或访谈，没有统计样本**；典型反馈为综合多人口述的方向性总结，非逐字引用。所有数字只写真实有的，不编用户量、留存或排名。

> 早期版本（PhilIntern）曾引用过「8 人访谈 / n=42 问卷」等样本数字，经核查为示意数据，已在站点与源码中标注为假设示例，不计入真实证据。
