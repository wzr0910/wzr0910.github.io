01
PhilIntern · 文科生 AI 求职助手
研究证据项 · 产品设计 与 开源
把文科生求职的信息差，做成「痛点 → 方案」讲清的 AI 工具集，覆盖求职全流程。
在线体验 GitHub
背景与问题

哲学与文科生找实习时，信息分散、不知投什么、不会准备，缺一个把「痛点 → 方案」讲清的抓手。我把自身困境抽象成通用工具：信息聚合 + 岗位匹配 + 案例展示，帮同类同学把求职想清楚。核心痛点：实习信息散、匹配度低、表达无抓手。

用户洞察与验证

调研方式：自身求职痛点 + 5+ 位文科同学轻量访谈 + 邀请 3 位目标用户内测。

  • 「想要能直接抄的简历结构」→ 推动多岗位简历生成器。
  • 「想知道这个岗到底要什么能力」→ 推动岗位匹配度分析。
  • 「匹配度想看得分理由，不想只看分数」→ 推动结果里写理由。
产品设计

用 DeepSeek + OpenCode 开发，7 天内上线 MVP 并 GitHub 开源。功能模块覆盖求职全流程：潜力挖掘器 / 多岗位简历生成器 / HR 沟通助手 / 岗位匹配度分析 / 能力速成清单 等 6 个工具模块。建立「AI 生成 + 人工校准」内容审核机制确保输出质量。工具链路（覆盖求职全流程）：

6 个模块全部经「AI 生成 + 人工校准」审核后开源在 GitHub，沉淀为可复用的案例与方法。

方法论沉淀：案例页结构为「痛点 → 需求 → 模块 → 迭代 → 复盘」，形成可复用方法论。

迭代与优化

从信息聚合 → 加匹配度分析 → 加可复用案例结构。下一步假设：按年级 / 专业做用户分层能提升建议采纳率；验证指标：内测用户「愿意照做」的比例。

复盘与收获

学到：「把个人困境抽象成通用工具」本身就是产品能力，也是我能讲清的方法论。若重来，会先做用户分层再写功能，而非先堆模块。

02
孩子的游戏 · AI 哲学共读平台
AI 主线项 · 产品设计 与 前端
用 3 轮 AI 对话把意义探索做成可共创、可分享的「人生宣言卡」，替代同质化心理测评。
在线体验
背景与问题

22–28 岁年轻人常有「想理清自己」的需求，但传统心理测评像考试、填完只有标签没有共鸣。我将意义探索设计为可共创、可分享的体验：用 3 轮引导式 AI 对话 引导用户生成一张人生宣言卡。痛点：测评缺真实对话感、哲学经典入门门槛高。

用户洞察与验证

调研方式：自身经历 + 社媒（小红书 / 播客）观察 + 亲友内测（3+ 人）。

  • 「比填表舒服，像有人陪我想」→ 验证「对话式」方向可行。
  • 「希望中间多追问我一句」→ 推动第 2 轮加深挖追问。
  • 「宣言卡想发给朋友看」→ 推动做保存与分享。
产品设计

3 轮对话流程：破冰 → 深挖 → 产出。反测评策略：不评分、只共创；用宣言卡把抽象的意义危机做成可分享产物。内容上用 AI 生成对话初稿，再人工校准尼采人设与语言风格确保一致性；原型先用纸面对话脚本跑通三轮节奏再接 AI 实现，分享用图片导出降低传播门槛。体验主流程：

迭代与优化

据小范围体验反馈，完成 2 轮对话流程迭代：从「问答式」改为「3 轮共创式」，第 2 轮加入深挖追问；并据测试反馈优化对话节奏与内容呈现，关注完成率与停留时长。下一步假设：分支防跑题能提升宣言卡与对话的相关度；验证指标：用户自评「这说的就是我」的占比。

复盘与收获

学到：AI 产品的核心是「引导结构」而非模型本身，流程设计决定体验上限。若重来，会先画对话分支树再写文案，而非反过来。

03
哲人王 · 网页文字治国游戏
旗舰项 · 产品设计 与 独立开发
将哲学治理命题做成多结局、数值驱动的文字决策游戏，让玩家在体验中理解不同治理取向的代价。
在线体验
背景与问题

哲学传播长期停留在文本，年轻人「读得进句子、难有参与感」。我将治理命题转化为可交互的决策：玩家以哲人王身份处理治国事件，每个选择触发数值后果，在体验中理解不同治理取向的代价。

用户洞察与验证

调研方式：自身作为目标用户 + 亲友试玩（5+ 人）；反馈为口述方向性总结。

  • 「选项后果看不清」→ 推动数值维度拆得更细、变化更直观。
  • 「想看不同结局但不想重开」→ 推动加结局分支提示。
  • 「文字量可再少」→ 推动事件文案更短、更有张力。
产品设计

核心系统：选项 → 数值变化 → 结局判定。我独立设计 20+ 治国事件、300+ 哲人台词分支，搭建「选项-数值-结局」叙事系统与数值平衡系统，10 天内从设计到上线。原型先用纸面事件卡跑通逻辑，再做前端实现。单事件处理流程：

迭代与优化

工程侧：测试中发现加载超时，独立排查定位到资源文件过大的根因，通过压缩资源与调整加载策略解决，体验明显变快。体验侧：数值维度变化更直观、结局更可感知，事件文案持续往「更短、更有张力」改。下一步假设：数值平衡表能让更多结局可达；验证指标：非哲学背景试玩者「能否说出治理取向差异」的完成率。

复盘与收获

学到：系统深度比美术更能留住人，文字产品的关键是「让选择有意义」。若重来，会先做数值平衡表再写事件，并更早邀请非哲学背景者试玩验证「门槛够不够低」。
